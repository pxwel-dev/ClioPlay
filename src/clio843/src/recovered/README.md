# Legacy helper references

`focusd.ghidra.c` and the `focusd/` assembly/data files are references recovered
from the installed helper, whose original `focusd_pac310.c` is missing. They are
not compilable original source and have no replacement-equivalence guarantee.
They are deliberately excluded from the native build.

The original helper remains at `card-template/clio843/focusd`. See
`SOURCE_STATUS.md` at the publication root for its role and the source gaps.
